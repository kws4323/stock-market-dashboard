# Market Pulse — Stock Dashboard

Public dashboard: https://kws4323.github.io/stock-market-dashboard/

## First-time setup
1. Settings → Pages → Deploy from a branch → main / (root) → Save.
2. Settings → Actions → General → Workflow permissions → Read and write permissions → Save.
3. Actions → Update market dashboard → Run workflow.

Scheduled at 06:30, 11:40, 18:00 Asia/Seoul; GitHub may delay runs.

The initial prototype uses yfinance (unofficial Yahoo Finance data). Confirm redistribution terms before public/commercial use. SEC 13F and congressional PTR are links, not yet automatic collectors.
