# Stock Dashboard

한국·미국 시장과 관심종목을 확인하는 GitHub Pages 대시보드입니다.

## 접속

https://kws4323.github.io/stock-market-dashboard/

## 시세와 새로고침

- GitHub Actions가 평일(UTC) 매시 17분·47분에 Yahoo Finance 데이터를 수집한 뒤 페이지를 배포합니다. GitHub 일정 실행은 지연 또는 누락될 수 있으며 실시간 시세가 아닙니다.
- 화면의 **저장 시세 새로고침**은 마지막으로 배포된 스냅샷을 다시 읽습니다. 버튼이 데이터 수집 작업을 즉시 실행하지는 않습니다.
- 즉시 수집: 저장소 Actions → Update market dashboard → Run workflow.
- 수집 시각과 각 종목의 시세 기준 시각을 별도로 표시합니다. 수집 실패 종목은 숫자를 만들어 표시하지 않습니다. 전체 수집 실패 시 기존 배포가 유지됩니다.
- 가격 차트의 마지막 일봉은 장중일 수 있습니다. 선물은 만기 교체 영향을 받을 수 있습니다. Yahoo Finance 데이터의 지연·누락·수정 가능성이 있습니다.

## 관심종목과 개인 메모

- 관심종목 목록과 메모는 현재 브라우저 localStorage에만 저장되며 GitHub로 전송하지 않습니다. 기기 간 동기화되지 않습니다.
- 수집 대상 종목은 `symbols.json`에 정의합니다. 목록에 없는 종목은 이 파일에 추가하고 workflow를 실행해야 시세를 볼 수 있습니다.
- 공개 저장소 및 공개 사이트입니다. 계좌 정보, API 비밀키, 보유 잔고는 넣지 마세요. 거래 기능은 없습니다.

## 구성

`site/index.html`: 반응형 화면 · `scripts/collect.py`: 실제 시세 수집 · `.github/workflows/pages.yml`: 수집 및 배포.

외국인·기관·개인 수급은 아래 KRX 연결 후 자동 수집합니다. 실적 캘린더 자동 연결은 포함하지 않습니다.

## KRX 수급 연결

1. KRX 정보데이터시스템 회원 계정을 준비합니다: https://data.krx.co.kr/
2. 이 저장소의 Settings → Secrets and variables → Actions → New repository secret에서 `KRX_ID`(KRX 아이디), `KRX_PW`(KRX 비밀번호)를 각각 저장합니다. 코드·이슈·채팅에는 비밀번호를 작성하지 않습니다.
3. Actions → Update market dashboard → Run workflow를 실행하거나 다음 예약 실행을 기다립니다.

상단 한국장 수급은 코스피·코스닥 주식을 대상으로 합니다(ETF·ETN·ELW·코넥스 제외). 외국인은 KRX의 ‘외국인’이며 ‘기타외국인’은 제외합니다. 기관은 ‘기관합계’입니다. 총매수·총매도·순매수금액과 금액 기준 순매도 TOP5를 표시합니다. 합산 순위는 두 시장 상위 후보를 같은 원화 금액 기준으로 비교합니다.

거래소 달력상 폐장 15분 후부터 자료를 수집하며, 기존 30분 간격 workflow에서 실행합니다. 20:15 이후 다시 받아 저녁 재조회 자료로 구분합니다. 제공 지연이나 수정이 있을 수 있습니다. 날짜가 바뀌어도 당일 자료인 것처럼 표시하지 않습니다.

매일 결과는 `data/flows.json`에 날짜별로 보존합니다. 연속 일수는 각 시장·투자자별 TOP5에 연속 포함된 거래일 수이며 주말·공휴일을 건너뜁니다. 같은 날 반복 갱신은 1일로 계산합니다. 중간 거래일 누락은 연속으로 연결하지 않으며, 확인 가능한 과거 자료 끝까지 포함된 경우 ‘최소 N거래일’로 표시합니다. 초기에는 최근 10거래일 중 최대 5거래일씩 보완합니다. 인증 실패·수집 실패 시 기존 자료를 보존하고 오류를 표시합니다.

KRX 계정이 없으면 순위와 금액은 미표시 상태입니다. 개인 순매매를 외국인·기관의 반대값으로 추정하지 않습니다. 현재 로그인된 웹사이트 쿠키를 저장소로 복사하지 않습니다.
